∙ Restaurer une sauvegarde

Une sauvegarde .json d'AZA, ou une ancienne base sessions.db. Remplace toute la base — séances, catalogue, presets, patchs, façades.
L'état actuel est d'abord écrit dans le dossier des sauvegardes (étiquette avant-restauration, jamais effacée) : une erreur se répare en un clic.

∙ Fusionner les séances d'une ancienne base

Upload un fichier sessions.db d'une version précédente.
Ses séances seules sont ajoutées à la base actuelle — les doublons (même date + machines) sont ignorés automatiquement.
Pour tout reprendre (catalogue, presets…), utilise plutôt « Restaurer » ci-dessus.
